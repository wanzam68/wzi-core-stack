## Documentation Principle

The Master SOP must distinguish between:

1. Version-controlled configuration.
2. Runtime-generated state.
3. Secrets and environment configuration.
4. Backup data.
5. Historical telemetry.
6. Safety copies and temporary files.
7. Release evidence.

Runtime data and secrets must never be committed as documentation evidence.
