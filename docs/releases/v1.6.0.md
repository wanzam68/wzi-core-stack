## Backup and Restore Safety

- Production backup deletion remains separately controlled.
- Database restore execution remains separately controlled.
- Restore assurance performs validation only.
- Retention assurance performs classification only.
- Milestone 6F does not authorize destructive recovery operations.

## Security

No committed passwords, API keys, tokens, private keys, or equivalent
credentials are permitted.

Environment-variable references used to obtain runtime secrets are not
secret values themselves.
