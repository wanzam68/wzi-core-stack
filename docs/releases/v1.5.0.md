## Release Scope

WZI Core Stack v1.5.0 introduces the Enterprise Operations Dashboard
and historical observability platform while preserving the existing
PostgreSQL, Redis, n8n, Caddy, backup, SSL, Telegram alerting and
disaster-recovery foundations.

## Security Controls

- Dashboard bound to `127.0.0.1:8088`
- Dashboard telemetry mount read-only
- No PostgreSQL credentials exposed to dashboard PHP
- Historical delivery uses sanitized JSON
- Secrets remain environment-managed
- Runtime telemetry, logs and backups excluded from Git
- Chart.js vendored locally
- Historical exporter separated from live telemetry collection
